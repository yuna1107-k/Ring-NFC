## 背景
Ring は公式 API がないため `python-ring-doorbell` の `Auth` を用いる。
初回のみ対話式で 2FA 認証し、以降はトークンを再利用・自動更新する。

## タスク
- [ ] `src/authorize.py`：メール/パスワード/2FA を対話入力しトークン取得
- [ ] トークン更新コールバックで `RING_TOKEN_CACHE` に保存（権限 600）
- [ ] 既存トークンがあれば有効性を検証し、失効時のみ再認証
- [ ] 認証後にデバイス一覧と検出 `location_id` を表示

## 受け入れ基準
- 初回実行でトークンが生成され、2回目以降は再認証不要
- パスワードはファイルに保存されない
- トークンファイルが 600 権限で作成される
