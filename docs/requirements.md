# 要件定義書 — Ring NFC モード切替

## 1. 目的

Raspberry Pi に接続した NFC リーダーに **NFC カード1枚**をかざすたびに、
Ring の**モードを在宅（home）⇔不在（away）でトグル**する。
スマートフォンやクラウド連携を介さず、Pi 単体でローカルに完結させる。

## 2. 背景

- Ring には公式な公開 API がないため、非公式ライブラリ
  [`python-ring-doorbell`](https://github.com/python-ring-doorbell/python-ring-doorbell)
  を利用する。
- カメラ / ドアベルのみの構成（Ring Alarm ベースステーションなし）を対象とする。
  この構成の「モード（Disarmed / Home / Away）」は
  ロケーション単位のエンドポイント `app.ring.com/api/v1/mode/location/{id}` で操作できる。

## 3. スコープ

### 3.1 対象（In Scope）
- NFC カードの UID 読み取り（PN532 / SPI 接続）
- 1枚のカードによる home ⇔ away のトグル
- Ring 認証（初回 2FA、以降トークン自動更新）
- 常駐実行（systemd）
- 設定・秘密情報の `.env` 管理（リポジトリは公開可能とする）

### 3.2 対象外（Out of Scope）
- Ring Alarm ベースステーションの武装/解除（WebSocket 経由。将来対応）
- スマホアプリ / クラウド連携 / 音声アシスタント連携
- 複数カード・複数モードの割り当て（将来拡張として設計に含めるが実装は任意）

## 4. 機能要件

| ID | 要件 |
|----|------|
| FR-1 | カードをかざすと現在のモードを取得し、home なら away、それ以外なら home に切り替える |
| FR-2 | 反応対象カードを UID で限定できる（未設定なら任意のカードで動作） |
| FR-3 | 同一カードの連続読み取りは一定秒数デバウンスし、多重切替を防ぐ |
| FR-4 | 初回のみ対話式で Ring にログインし、トークンをローカルにキャッシュする |
| FR-5 | 起動時に現在モードと設定内容をログ出力する |
| FR-6 | モード切替の成否をログ出力する |
| FR-7 | 電源投入で自動起動し、異常終了時は自動再起動する |

## 5. 非機能要件

| ID | 要件 |
|----|------|
| NFR-1 | 秘密情報（トークン等）と環境依存設定はリポジトリにコミットしない（`.env` / キャッシュは gitignore） |
| NFR-2 | 設定はすべて環境変数（`.env`）で与えられ、コード変更なしに挙動を変えられる |
| NFR-3 | トークンキャッシュはファイル権限 600 で保存する |
| NFR-4 | ネットワーク断・API エラー時もプロセスは停止せず、次のタップで再試行できる |
| NFR-5 | Raspberry Pi OS（32/64bit）上の Python 3.9+ で動作する |

## 6. 制約・前提

- PN532 は SPI 接続を推奨（Pi では I2C/UART が不安定なことが多い）。
- Ring 非公式 API のため、Ring 側の仕様変更で動作しなくなる可能性がある。
- 対象ロケーションで「モード」機能が有効である必要がある（カメラ0台等では不可の場合あり）。

## 7. 受け入れ基準（例）

- 登録カードをかざすと数秒以内に Ring アプリ上のモードが切り替わる。
- home のときにかざすと away に、away/disarmed のときにかざすと home になる。
- Pi 再起動後、手動操作なしにサービスが復帰する。
- リポジトリを公開しても秘密情報が含まれない。
